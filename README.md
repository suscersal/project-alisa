# СпортОбъекты

Карта спортивных объектов на Яндекс Картах: свои объекты в базе + автопоиск спортплощадок из OpenStreetMap.

## Запуск (из папки `code`)

```bash
cd code
pip install -r requirements.txt
python backend.py
```

Откройте http://127.0.0.1:8000 (страницу отдаёт сам `backend.py`, не открывайте `index.html` как файл).
База `sports.db` создаётся автоматически при первом запуске.

## Что умеет

- Карта: Яндекс Карты JS API 2.1. Яндекс пишет в консоль `Invalid API key`, если ключа нет; если карта перестанет грузиться — добавьте `apikey=...` в ссылку на скрипт в `index.html`.
- Клик по метке (своей или из OpenStreetMap) или по названию в таблице открывает карточку с информацией; свой объект можно удалить прямо из неё.
- Добавление объекта: название, тип, широта, долгота. Проверки: пустые поля, диапазон координат, дубликаты названий (см. `plan.dx`).
- Автопоиск спортобъектов из OpenStreetMap в видимой области карты.

## Структура

- `code/backend.py` — FastAPI + SQLite
- `code/index.html` — интерфейс
- `plan.dx` — бизнес-требования
- `docs/task.md` — текст учебного задания (бывший `FILE/2`)
