
# Проект 2: Карта спортивных объектов (интерактивная)

**Сценарий**  
Создайте сервис для отображения и управления списком спортивных объектов школы или района. Можно реализовать как простой веб-интерфейс с картой (например, используя Folium или статический HTML с JavaScript) либо как REST API для получения координат объектов. Главное – возможность добавлять, редактировать и просматривать объекты с географической привязкой. Если времени мало, ограничьтесь API, возвращающим GeoJSON или список объектов с координатами, а визуализацию сделайте опционально.

**Роли и распределение задач**

| Ученик A (Бэкенд и данные) | Ученик B (Визуализация и интерфейс) |
|----------------------------|-------------------------------------|
| Создать модель `SportObject` (`id`, `name`, `type`, `lat`, `lon`, `description`) | Подготовить HTML-шаблон с картой (Leaflet или OpenStreetMap) |
| Реализовать CRUD-эндпоинты для объектов: `GET /objects`, `POST /objects`, `PUT /objects/{id}`, `DELETE /objects/{id}` | Написать JavaScript-код для загрузки данных с бэкенда и отображения маркеров на карте |
| Хранить данные в `sports.json` (список объектов) | Обеспечить форму добавления нового объекта через интерфейс (отправка POST-запроса) |
| Возвращать данные в формате JSON, пригодном для отображения (можно GeoJSON) | При клике на маркер показывать информацию об объекте |

**Технические детали и подсказки**

- Структура `sports.json`:
```json
[
  {"id": 1, "name": "Футбольное поле", "type": "стадион", "lat": 55.751244, "lon": 37.618423, "description": "Поле с искусственным покрытием"},
  {"id": 2, "name": "Бассейн", "type": "плавание", "lat": 55.755826, "lon": 37.617300, "description": "25 метров, 4 дорожки"}
]
```

- Для быстрой карты используйте Leaflet.js – достаточно подключить CSS/JS и несколько строк кода:
```html
<link rel="stylesheet" href="https://unpkg.com/leaflet@1.9.4/dist/leaflet.css" />
<script src="https://unpkg.com/leaflet@1.9.4/dist/leaflet.js"></script>
<div id="map" style="height: 400px;"></div>
<script>
  var map = L.map('map').setView([55.75, 37.62], 13);
  L.tileLayer('https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png').addTo(map);
  // Загрузить объекты через fetch('/objects') и добавить L.marker
</script>
```

- FastAPI может отдавать статические файлы:
```python
from fastapi.staticfiles import StaticFiles
app.mount("/static", StaticFiles(directory="static"), name="static")
```

Для упрощения можно сделать только API и предложить проверять работу через Swagger (/docs). Визуализация – дополнительный плюс.

**Тестирование**
- Запустите сервер, откройте /docs и проверьте CRUD объектов.
- Если реализован интерфейс, откройте главную страницу, убедитесь, что карта отображается и маркеры загружаются.

**Критерии приёмки**
- API позволяет управлять списком спортивных объектов.
- Данные сохраняются в JSON.
- (Опционально) Есть веб-страница с интерактивной картой, маркеры соответствуют объектам из базы.
- Код понятно разделён между участниками.
